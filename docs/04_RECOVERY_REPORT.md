## Выполненные проверки

- Исходный ZIP: CRC, SHA-256 каждого файла по манифесту — успешно.
- Установка backend по requirements.lock и frontend через npm ci — успешно.
- pytest: 25 новых/адаптированных проверок восстановления — успешно.
- Vitest: 33 сохранённых теста, 7 файлов — успешно.
- Ruff check и format --check для backend — успешно.
- Frontend TypeScript/Vite build и ESLint — успешно.
- docker compose config --quiet для нового локального стека — успешно.
- Alembic: одна вершина `0007_summaries`; генерация SQL семи миграций offline — успешно.

Тесты backend проверяют health, безопасные ошибки, анонимный доступ, CSRF,
отсутствие отражения учётных данных, опасные пути ZIP, нормализацию TXT и диапазоны цитат.
БД и Redis в этих проверках не используются; это не 173 исторических теста.
Есть предупреждение DeprecationWarning в Starlette/AnyIO; тесты прошли.

Не выполнялись: Docker build, запуск нового стека, применение миграций в PostgreSQL,
восстановление логического дампа, сквозной сценарий книги/очереди/резюме и реальные провайдеры.
Без этих проверок нельзя объявлять приложение готовым к эксплуатации.
